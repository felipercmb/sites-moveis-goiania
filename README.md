# Mobiliário de Goiânia — 20 propostas

[**Abrir o painel**](https://felipercmb.github.io/sites-moveis-goiania/)

Vinte sites estáticos de apresentação, com galeria de móveis, filtros e consultas preparadas para revisão do visitante. Cada loja tem sua subpasta, fontes e imagens locais.

São propostas independentes de redesign, sem vínculo oficial com as empresas. Fotografias partem de publicações dos perfis; ambientações com IA são identificadas e oferecem acesso aos registros originais. Preços, estoque e condições atuais dependem de consulta às lojas.

## Publicação

GitHub Pages publica a raiz da branch `main`. O arquivo `.nojekyll` preserva as pastas de recursos que começam com sublinhado. Não há build, dependências de servidor ou formulários com envio automático.

Para prévia local, execute `python3 -m http.server 4173` e abra `http://localhost:4173/`.

## Refinamento de apresentação

As vinte propostas receberam ajustes de tipografia, proporção das fotografias, navegação e controles de toque. A composição se adapta a celulares, tablets e computadores; os formulários usam campos de 16 px e as galerias preservam a fotografia inteira. As ambientações e os contatos originais foram mantidos.

As fotografias agora recebem o acabamento arredondado no contorno da imagem visível, inclusive quando o enquadramento preserva a proporção original. Foram corrigidos recortes de catálogo e faixas embutidas em algumas publicações; imagens tratadas com IA mantêm identificação e acesso ao registro original.
